# Project agent instructions

## Attribution / authorship (REQUIRED)

Do NOT represent the AI assistant (Claude, Claude Code, or any AI/agent) as a
contributor, author, or co-author of this project. Specifically:

- Do NOT add `Co-Authored-By: Claude ...` (or any AI/agent) trailers to commit
  messages.
- Do NOT add "Generated with Claude Code", "🤖", or any similar assistant
  attribution to commit messages, pull-request or issue bodies, release notes,
  code comments, or documentation.
- Commits, PRs, and all project artifacts are authored solely by the human author.
